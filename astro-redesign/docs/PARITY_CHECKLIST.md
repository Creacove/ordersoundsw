# Visual parity checklist

Use this during every screenshot review.

## Environment
- [ ] Same warm ivory/greige range as reference
- [ ] Same bright upper-left light wash
- [ ] Same subtle floor/wall horizon
- [ ] Same soft foreground/plant-shadow character
- [ ] No darker cinematic reinterpretation

## Copy/UI
- [ ] Brand/nav starts at the same horizontal rhythm
- [ ] H1/H2 line breaks match reference
- [ ] Headline weight is not too bold or too thin
- [ ] Gray support copy contrast matches
- [ ] Purple `DESK` is restrained, not neon
- [ ] CTA size/radius/vertical alignment match

## Record object
- [ ] Sleeve is ivory, not white or beige-brown
- [ ] Sleeve paper texture is subtle at normal viewing distance
- [ ] Purple arc position/size matches front reference
- [ ] Back arc is limited to lower-right
- [ ] Vinyl offset from sleeve matches
- [ ] Center label size/color matches
- [ ] Disc grooves are present but not over-sharpened
- [ ] Rainbow/iridescence appears primarily on right-hand regions like reference
- [ ] Sleeve has believable thin edge at 90°

## Motion
- [ ] Only sleeve rotates 180°
- [ ] Vinyl remains stable
- [ ] No loop
- [ ] No bounce
- [ ] Text transitions only after back is readable
- [ ] Result change is subtle and understandable

## Performance
- [ ] Poster is immediate
- [ ] Poster/live scene registration is identical
- [ ] No layout shift
- [ ] Renderer idles after final state
